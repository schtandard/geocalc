# geocalc

A Python 3 package for calculating physical parameters for device geometries.
Have a look at [the docs][docs].

[docs]: http://www.zwo.pit.uni-tuebingen.de/geocalc/

## Building the Documentation

In the folder `docs`, run

```shell
make html
```

If you're using PowerShell, you need to say

```shell
start make.bat html
```

You can then open `docs/build/index.html` in any browser.

If you get errors, check that you have installed both `sphinx` and `sphinx-rtd-theme`.
